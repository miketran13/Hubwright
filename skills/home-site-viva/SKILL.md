# Home site and global navigation

The **home site** is the intranet's front door. You need one to turn on **global navigation**,
the SharePoint app bar, which appears on every site and page.

- Add your hubs to global navigation so people can find them from anywhere.
- **Should the home site be a hub?** Make it a hub when you have one distinct "official"
  intranet with its own brand and search scope. With several hubs, Microsoft suggests a regular
  home site and the app bar for global navigation.
- Global navigation labels must be broad. Test them with real users before launch.
