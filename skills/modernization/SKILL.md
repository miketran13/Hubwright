# Modernization

Classic SharePoint still runs, but the modern experience is where Microsoft invests: modern pages,
hubs, modern themes, Viva Connections and Copilot.

- Use **modern themes with modern pages**. A classic theme on a modern page is converted, and
  readability needs testing.
- Subsites remain supported as a classic feature. Plan new structure with hubs.
- Classic publishing, custom script, InfoPath forms and classic workflows are rules of thumb here.
  The retirement-notice sources still have to be harvested; see the roadmap.
