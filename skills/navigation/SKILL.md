# Site navigation

About 70% of visitors start by browsing, so navigation tells the story of a site. Plan it from the
reader's point of view, use clear and mutually exclusive labels, and use progressive disclosure:
a few categories that lead to more.

- Cascading and mega menus both support **three levels**. Use the mega menu when you use all
  three, and cascading when two are enough.
- A **label** groups links. It should always have at least one link below it.
- Communication sites ship with Documents / Pages / Site contents links. Replace them before
  launch, because readers care about subjects, not content types.
- **Link to pages, not documents.** A page keeps the reader in the site's context and is easier
  to read on mobile.
- Use **audience targeting** for links only some people can open.
