# Search and findability

Search covers the "I know it exists but not where" and "I don't know if it exists" cases.

- Add **acronyms, bookmarks, Q&A, floor plans and locations** in Microsoft Search for the things
  people look for most.
- Hubs give each family a **search scope**. That is one reason to have more than one hub.
- Metadata (columns and content types) improves search and lets Highlighted content web parts
  connect related pages.
